HTC released the entry-level smartphone HTC Desire C to the Bangladeshi market in June 2012 for users seeking affordable options. This smartphone operates a 3.5-inch IPS LCDdisplaywhich provides 320 x 480 pixels resolution. The power system of the device relies on the Qualcomm Snapdragon S1 chipset with its single-core 600 MHz Cortex-A5 CPU and Adreno 200 GPU. This model has a 5 MP rearcamerathat allows users to record VGA videos. The removablebatteryof this device provides 1230 mAh capacity. The HTC Desire C operates under Android 4.0 Ice Cream Sandwich by using HTC's Sense UI. The HTC Desire C operates with a single SIM card system while providing Wi-Fi 802.11 b/g/n, Bluetooth 3.0, GPS connectivity options. The available color options for this device include Polar White, Stealth Black and Flamenco Red. The HTC Desire C price in Bangladesh is BDT 21,390 (Official) with 512MB of RAM and 4GB of phone storage.
