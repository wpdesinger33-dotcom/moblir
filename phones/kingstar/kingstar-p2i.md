The Kingstar P2i is a basic feature phone in the market, which is affordable to many people in the society. It comes with a 1.8 inches TFT color screen with a resolution of 128 x 160 pixels. The phone has a 1.3MP primary camera. It also comes with a microSD card slot for a memory expansion up to 16GB. It has basic features such as the FM radio. With Li-Ion 1200mAh battery, standby up to 310 hours and talk time up to 5 hours. The device also has dual SIM which means the user can be able to use two numbers at the same time. Comms features are GPRS class is GPRS class is class 10 and EDGE; and Bluetooth version is v2.0. The Kingstar P2i price in Bangladesh is BDT 1,099 (Official).
