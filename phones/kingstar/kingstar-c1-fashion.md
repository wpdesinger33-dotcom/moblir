Kingstar C1 Fashion is a feature mobile that is primarily targeted at calling and texting. It includes a 1.77 inches TFT color screen with the 128х160 dots displays. The phone supports a 1.3MP on the rear facing camera. It also has a microSD card slot for additional storage with taking up external memory that may go up to 8GB. It has features that are core for the smartness like the FM radio. It has a Li-Ion 1200 mAH battery, it supports as much as 410 hours standby times and 5 hours talk times. The multi connectivity feature includes a SIM card dual connection that enables the user to run two lines simultaneously. The Kingstar C1 Fashion price in Bangladesh is BDT 899 (Official).
