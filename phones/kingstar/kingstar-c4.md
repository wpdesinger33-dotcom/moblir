The Kingstar C4 is an entry-level smartphone that offers call only features and enables communication of basic services. It has a 1.8 inches TFT display with the maximum resolution of 128 x 160 pixels. The phone has built-in a 1.3MP primary camera. It is driven by Li-Ion 2000 mAh battery and supports up to 410 hours of standby time and up to 7 hours of talk time. The device also features dual Sims where the user can be able to use two different numbers at the same time. The communication technologies supported are GSM, and Bluetooth v2.0. It also has a microSD card slot for added memory storage, expandable to 8GB. It has other features such as FM radio, loud speaker, and document reader. The Kingstar C4 price in Bangladesh is BDT 1,295 (Official).
