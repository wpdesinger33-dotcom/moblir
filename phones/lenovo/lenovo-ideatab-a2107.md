Lenovo IdeaTab A2107 is an Android tablet, it was released in 2013. The tablet has a 7.0-inch TFT, with support for a resolution of 600 x 1024 pixels. The Tablet computer utilizes the MediaTek MT6575 processor that consists of 1.0 GHz Cortex-A9 CPU as well as PowerVR SGX531 GPU. The IdeaTab A2107 has 1GB RAM and has fixed memory of 16GB internal storage, which can however be expanded using a microSD card. It has only a 3.15 MP rear camera for the rear end and a 0.3 MP front camera. The tablet features Google android 4.0.3 operating system, otherwise known as Ice Cream Sandwich. It is 3550mAh which suffices the battery requirements required to run the IdeaTab A2107 in day to day usage. The Lenovo IdeaTab A2107 price in Bangladesh is BDT 17,200 (Official).
